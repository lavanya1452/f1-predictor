# F1 Predictor

An end-to-end machine learning and Monte Carlo simulation system for Formula 1 race and championship prediction.

## Planned Architecture

- Historical F1 data ingestion
- Canonical data schema
- Leakage-safe feature engineering
- Baseline models
- XGBoost / LightGBM
- Probability calibration
- Race finishing-order prediction
- Plackett-Luce race-order simulation
- F1 scoring
- Monte Carlo championship simulation
- Streamlit dashboard
- What-if scenarios
